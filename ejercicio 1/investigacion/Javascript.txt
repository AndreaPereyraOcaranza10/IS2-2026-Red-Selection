¿Qué es JavaScript? 
JavaScript es un lenguaje de programación interpretado, de alto nivel y de tipado dinámico, creado originalmente para ejecutarse en el navegador y dotar de comportamiento dinámico a las páginas web. 

¿Para qué sirve?
JavaScript se utiliza principalmente para agregarle interactividad y comportamiento dinámico a las páginas web: validar formularios, actualizar contenido sin recargar la página, mostrar u ocultar elementos, generar animaciones y responder a acciones del usuario (clics, teclas, envío de datos). Es el complemento de HTML (estructura) y CSS (estilo) para lograr páginas interactivas. 
Actualmente también se utiliza fuera del navegador, por ejemplo del lado del servidor mediante Node.js, aunque su rol principal en el desarrollo web tradicional es el lado del cliente. 

¿Cuáles son sus características? 
Lenguaje del lado del cliente: se ejecuta en el navegador del usuario, permitiendo modificar una página sin necesidad de recargarla ni volver a pedirle algo al servidor.
Interpretado: no necesita compilarse; el navegador lo lee y ejecuta directamente.
Orientado a eventos: permite programar respuestas a acciones del usuario (clic en un botón, envío de un formulario, escritura en un campo, etc.).
Manipulación del DOM: es el lenguaje que permite acceder y modificar dinámicamente los elementos HTML de una página (agregar, eliminar, cambiar contenido o estilos).
Validación de formularios: se usa comúnmente para validar datos ingresados por el usuario antes de enviarlos al servidor.
Independiente de la plataforma: corre en cualquier navegador moderno, sin importar el sistema operativo.
Se integra directamente en el HTML: mediante la etiqueta <script>, ya sea embebido o en archivos externos.
Complementa a HTML y CSS: mientras HTML define la estructura y CSS el estilo, JavaScript aporta el comportamiento e interactividad.
Débilmente tipado: no es necesario declarar el tipo de dato de una variable.
Hoy también se usa del lado del servidor (Node.js), aunque su origen y uso principal en este contexto es el navegador.

¿Cuáles son sus ventajas y desventajas? 
Ventajas:
Es el único lenguaje que entienden todos los navegadores de forma nativa, sin instalar nada.
Permite validar datos y dar feedback inmediato al usuario sin depender del servidor.
Se integra fácilmente con HTML y CSS.
Amplia cantidad de documentación, ejemplos y librerías disponibles (jQuery, Bootstrap JS, etc.).
Desventajas:
El código es visible para cualquiera que inspeccione la página (no es seguro para lógica sensible).
Su ejecución depende del navegador del usuario, que puede tenerlo desactivado o comportarse distinto entre navegadores.
El tipado dinámico puede generar errores no detectados hasta la ejecución.
Si el código es muy pesado o mal escrito, puede hacer que la página responda más lento.

¿Qué es DOM?
El DOM (Document Object Model) es una representación en forma de árbol de objetos que el navegador genera a partir del documento HTML de una página. Cada elemento HTML se convierte en un nodo dentro de dicho árbol, lo que permite a JavaScript acceder y manipular la estructura, el contenido, los atributos y los estilos de la página de forma dinámica, así como responder a eventos del usuario (clics, teclas, envíos de formulario, etc.).
